# 통계 기능 아이디어

## 화면 구조 방향

- 모든 통계 정보는 **`DiaryChartScreen` 하나에 집중**
- 섹션별로 UI를 구분하고 **수직 스크롤(LazyColumn)** 로 탐색
- 현재 섹션 순서:
    1. 연속 작성 스트릭 배너 (2일 이상인 경우만 노출)
    2. 월 이동 헤더 (MonthHeader)
    3. 이달의 감정 Top 3
    4. 감정 통계 바 차트

## 감정 통계

- **감정 달력 히트맵** — 월별 달력에 감정별 색상으로 칠하기
- **감정 변화 추이** — 주/월 단위로 특정 감정의 빈도 꺾은선 그래프
- **감정 연속 기록** — "행복 3일 연속", "최장 긍정 연속 N일"
- **요일별 감정 패턴** — 월요일엔 어떤 감정이 많은지
- **시간대별 감정** (작성 시각 기록 시) — 아침/저녁 기분 차이

## 작성 습관 통계

- **연속 작성 스트릭** — GitHub 잔디처럼 연속 기록 유지
- **월별 작성 횟수 추이** — 꾸준히 쓰고 있는지 바 차트
- **가장 많이 쓴 요일/시간대**
- **평균 일기 길이** — 감정별로 글자 수가 다른지 비교

## 키워드 / 내용 분석

- **자주 등장하는 단어 워드 클라우드**
- **감정별 자주 쓰는 단어** — 행복할 때 vs 슬플 때 자주 나오는 단어
- **특정 단어가 등장한 날의 감정 분포**

## 회고 / 리포트

- **월간 리포트** — "이번 달 가장 많은 감정은 OO, N일 작성"
- **연간 감정 결산** — 올해의 감정 TOP3, 최다 작성 달
- **N년 전 오늘** — 과거 같은 날 일기 다시 보기

## 우선순위 제안

현재 `DiaryChartScreen`이 이모티콘 빈도 통계를 제공 중이므로, 자연스러운 확장 순서:

1. **감정 달력 히트맵** — 기존 캘린더 화면과 연계 가능
2. **월간 리포트** — 현재 차트 화면을 리포트 형식으로 확장
3. **연속 작성 스트릭** — 동기부여 기능과 연계 가능

## 연속 작성 스트릭 — 상세 기획

### 개요

매일 일기를 작성한 연속 일수를 추적해 사용자의 꾸준한 기록 습관을 유도한다.

### 데이터 모델

`DiaryEntity`의 `year / month / day` 필드를 기준으로 계산 (별도 테이블 불필요).

```
현재 스트릭  : 오늘 기준으로 연속 작성한 일수
최장 스트릭  : 역대 최고 연속 기록
총 작성 일수 : 전체 기간 동안 일기를 쓴 날의 수
```

### 계산 로직

```
1. DB에서 작성된 날짜 전체를 오름차순으로 가져온다
2. 날짜를 LocalDate로 변환해 중복 제거 후 정렬
3. 인접한 날짜가 1일 차이면 연속으로 카운트
4. 오늘 또는 어제 날짜가 포함되어야 현재 스트릭 유효
   → 오늘/어제에 작성이 없으면 현재 스트릭 = 0
```

### Domain 레이어

```kotlin
// UseCase
data class StreakResult(
    val currentStreak: Int,
    val longestStreak: Int,
    val totalWrittenDays: Int,
)

class GetStreakUseCase(private val diaryRepository: DiaryRepository) {
    suspend operator fun invoke(): StreakResult
}
```

`DiaryRepository`에 `getAllDiaryDates(): List<LocalDate>` 추가 필요.

### UI 표시 위치 (안)

| 위치               | 표시 방식                  |
|------------------|------------------------|
| 홈/캘린더 상단         | "🔥 N일 연속 작성 중!" 배너    |
| DiaryChartScreen | 스트릭 카드 (현재/최장/총 일수)    |
| 일기 저장 직후         | "N일 연속! 오늘도 기록했어요" 스낵바 |

### 엣지 케이스

- 같은 날 일기를 여러 번 수정해도 1일로 카운트
- 날짜가 없는 경우(DB 비어있음) → 스트릭 0
- 어제 작성 후 오늘 미작성 → 현재 스트릭 0, 최장 스트릭은 유지
