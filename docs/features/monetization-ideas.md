# 수익화 아이디어

감정 다이어리 앱 특성에 맞는 수익화 전략 목록입니다.
현재 앱에는 배너/리워드 광고, `MongsilStoreScreen`(플레이스홀더), `PdfExportScreen`(플레이스홀더)이 이미 존재합니다.

---

## 현재 상태

| 기능             | 상태     |
|----------------|--------|
| 배너 광고 (AdMob)  | 구현 완료  |
| 리워드 광고 (AdMob) | 구현 완료  |
| 몽실 스토어 화면      | 플레이스홀더 |
| PDF 내보내기 화면    | 플레이스홀더 |

---

## 1. 광고 (현재 구조 확장)

### 리워드 광고 연계 강화

- 광고 시청 → 스트릭 보호권 지급 (동기부여 기능과 연동)
- 광고 시청 → 잠긴 이모티콘 1일 체험
- 광고 시청 → PDF 내보내기 1회 무료

현재 `ShowRewardedAd` 컴포넌트 이미 존재하므로 보상 항목만 추가하면 됨

---

## 2. 인앱 결제 — 몽실 스토어 (MongsilStoreScreen 활용)

### 프리미엄 구독 (월정액)

가장 안정적인 수익 모델. 무료/프리미엄 기능을 명확히 분리.

| 기능           | 무료        | 프리미엄 |
|--------------|-----------|------|
| 일기 작성        | 무제한       | 무제한  |
| 기본 이모티콘      | O         | O    |
| 프리미엄 이모티콘 팩  | X         | O    |
| PDF 내보내기     | X (광고 시청) | 무제한  |
| 광고 제거        | X         | O    |
| 테마/폰트 전체 해금  | X         | O    |
| 월별 감정 리포트 상세 | X         | O    |

### 일회성 구매 아이템

- **이모티콘 팩** — 시즌별 테마 팩 (봄, 여름, 크리스마스 등) 판매
- **테마 팩** — 다크, 파스텔, 모노톤 등 UI 테마
- **광고 제거** — 영구 1회 구매

---

## 3. PDF 내보내기 수익화 (PdfExportScreen 활용)

일기를 PDF로 내보내는 기능 자체를 수익화 포인트로 활용.

- **무료**: 월 1회 내보내기 (또는 광고 시청 후 1회)
- **프리미엄**: 무제한 내보내기
- **꾸미기 옵션**: 표지 디자인, 레이아웃 선택은 유료

---

## 4. 이모티콘 팩 시즌제

- 계절/기념일마다 한정 이모티콘 팩 출시
- 한정판 느낌으로 희소성 부여 → 구매 욕구 자극
- 기존 `Emoticon` 모델 + `EmoticonApi` 구조 활용 가능

---

## 5. 클라우드 백업 (장기)

현재 `BackupRestoreScreen` 존재. 로컬 백업은 무료, 클라우드 자동 백업은 프리미엄으로 차별화.

- 무료: 로컬 내보내기/가져오기
- 프리미엄: 클라우드 자동 백업 + 기기 간 동기화

---

## 구현 우선순위

| 난이도 | 기능           | 기대 수익 | 이유          |
|-----|--------------|-------|-------------|
| 낮음  | 리워드 광고 연계 강화 | 중     | 기존 코드 재활용   |
| 낮음  | PDF 내보내기 유료화 | 중     | 화면 이미 있음    |
| 중간  | 이모티콘 팩 인앱 결제 | 중~고   | 스토어 화면 활용   |
| 중간  | 광고 제거 일회성 구매 | 중     | 유저 페인포인트 해소 |
| 높음  | 프리미엄 구독      | 고     | 기능 설계 선행 필요 |
| 높음  | 클라우드 백업      | 고     | 서버 필요       |

## 추천 전략

1. **단기**: 리워드 광고를 동기부여 기능(`motivation-reward-ideas.md`)과 연계해 광고 수익 극대화
2. **중기**: 이모티콘 팩 + PDF 내보내기 유료화로 인앱 결제 도입
3. **장기**: 구독 모델로 전환 (충성 유저 확보 후)
