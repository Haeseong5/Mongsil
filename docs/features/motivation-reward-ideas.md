# 동기부여 & 보상 기능 아이디어

일기를 지속적으로 쓸 동기를 부여하고 도파민을 유발하는 기능 아이디어 목록입니다.

---

## 1. 스트릭 & 연속 기록

- **연속 작성 스트릭** — GitHub 잔디처럼 캘린더에 색상으로 표시. N일 연속 시 특별 이펙트
- **최장 스트릭 기록** — "역대 최고 기록 갱신!" 알림
- **스트릭 보호권** — 광고 보상으로 하루 빠져도 스트릭 유지 (광고 기능 연동)

## 2. 감정 통계 인사이트

- **월별 감정 리포트** — "이번 달 가장 많이 느낀 감정은 😊 기쁨이에요"
- **감정 변화 그래프** — 일주일/한 달 트렌드 시각화
- **"오늘의 나 vs 1년 전의 나"** — 같은 날짜 과거 일기 랜덤 회상

## 3. 성장 시스템

### 레벨/칭호

작성 횟수에 따라 칭호 부여 예시:

| 작성 횟수  | 칭호     |
|--------|--------|
| 1~9일   | 감정 초보  |
| 10~29일 | 감정 탐험가 |
| 30~99일 | 감정 기록자 |
| 100일+  | 감정 마스터 |

### 이모티콘 해금

- 처음엔 기본 이모티콘 몇 개만 사용 가능
- 일기를 많이 쓸수록 새 이모티콘 잠금 해제
- 잠긴 이모티콘은 선택 화면에서 흐릿하게(🔒) 표시 → 궁금증 유발
- 기존 `Emoticon` 모델에 `isUnlocked`, `unlockCondition` 필드 추가로 구현 가능

해금 조건 예시:

| 조건       | 해금 보상    |
|----------|----------|
| 7일 연속 작성 | 달밤 이모티콘  |
| 30일 달성   | 반짝임 이모티콘 |
| 100일 달성  | 레어 이모티콘  |

### 일기장 꾸미기

- 스트릭/레벨 보상으로 테마/폰트 잠금 해제

## 4. 챌린지

- "7일 동안 매일 감사한 일 기록하기" 같은 기간 미션 제공
- 완료 시 칭호 또는 이모티콘 보상

## 5. 소셜 (장기)

- **익명 공개 옵션** — 비슷한 감정의 다른 사람 글 구경 (선택적)
- 서버 구축 필요, 장기 과제

---

## 구현 우선순위

| 난이도 | 기능           | 이유                 |
|-----|--------------|--------------------|
| 낮음  | 스트릭 + 캘린더 잔디 | 캘린더 이미 있음, 데이터도 있음 |
| 낮음  | 이모티콘 해금      | Emoticon 모델 이미 존재  |
| 중간  | 월별 감정 리포트    | DB 데이터 집계만 필요      |
| 중간  | 레벨/칭호 시스템    | 간단한 로컬 로직          |
| 높음  | 소셜 기능        | 서버 필요              |
